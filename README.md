# 💧 Water Intake Tracker

A beginner-friendly Python project that helps users track their daily water consumption and monitor their hydration progress.

## ✨ Features
- Set a daily water intake goal.
- Add water consumed in milliliters (ml).
- View total water consumption.
- Check the remaining water needed to reach the goal.
- View progress as a percentage.
- Validate water intake amounts.
- Simple menu-driven interface.

## 🛠️ Concepts Learned
- Variables and data types
- User input and output
- While loops
- If-elif-else statements
- Arithmetic operators
- Built-in functions: `min()`, `max()`, and `round()`

## 💻 Technologies Used
- Python
